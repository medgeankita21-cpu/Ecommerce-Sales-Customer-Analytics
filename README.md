# E-Commerce Sales & Customer Analytics Dashboard

## Project Overview
This project analyzes e-commerce sales and customer data using Power BI to identify sales trends, customer behavior, product performance, regional performance, and payment preferences.

## Tools Used
- Power BI
- Excel
- CSV
- DAX

## Key KPIs
- Total Sales: ₹8.66M
- Total Profit: ₹2M
- Total Orders: 1K
- Total Customers: 285

## Dashboard Analysis
- Monthly Sales Trend
- Category-wise Sales Analysis
- Product-wise Sales Analysis
- Region-wise Sales Analysis
- Payment Mode Analysis
- Interactive Slicers

## Business Insights
- Electronics generated the highest category-wise sales.
- Wireless Headphones was the top-selling product.
- North region recorded the highest sales.
- Credit Card had the highest sales contribution among payment modes.
- The business generated ₹8.66M in total sales and ₹2M in total profit.

## Objective
To use data analytics and visualization techniques to generate meaningful business insights and support data-driven decision making.
